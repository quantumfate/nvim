# Package dependencies for this Neovim config
#
# Every name below was verified against the Arch repos (pacman -Si) and the
# AUR RPC. Tags:
#   [core] / [extra] = official repos -> pacman -S <pkg>
#   [AUR]            = Arch User Repo -> yay/paru -S <pkg>
#
# The ansible role (ansible/roles/nvim) installs this whole set through yay in
# one transaction, so repo and AUR packages are mixed freely.
#
# Bundled with lazy.nvim via git, so NOT Arch packages:
#   neovim plugins themselves (see lazy-lock.json)
#   treesitter parsers (built on demand)
#
# Most LSP/format/lint/dap tools can also be auto-installed by Mason on first
# launch (:Mason). Prefer the pacman/AUR package to keep them system-managed.

## Core (required)
- neovim          [extra]   # >= 0.11 (nightly recommended)
- git             [extra]
- base-devel      [core]    # gcc + make; builds treesitter parsers + LuaSnip jsregexp
- tree-sitter-cli [extra]   # parser installs on the main branch
- ripgrep         [extra]   # grep/picker backend
- fd              [extra]   # file finder backend
- fzf             [extra]   # fuzzy matching
- curl            [core]    # Mason downloads + nvim-dbee binary fetch
- wget            [extra]

## Language runtimes (needed so the Mason tools actually run)
- nodejs          [extra]
- npm             [extra]
- pnpm            [extra]
- go              [extra]
- rustup          [extra]   # rust-analyzer / rustfmt / clippy as rustup components
- python          [extra]
- uv              [extra]   # python package manager
- lua51           [extra]   # Lua 5.1 for luarocks/nlua (Lua debugging)
- luarocks        [extra]
- zig             [extra]   # zig fmt (conform "zigfmt")

- nvim-treesitter  -> C compiler + make + tree-sitter-cli
- nvim-dbee        -> curl/wget fetches prebuilt binary on install
