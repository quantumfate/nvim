# AUR / Package dependencies for this Neovim config
#
# Everything this config needs, mapped to its Arch package name.
#   [extra] = official repo  -> install with: pacman -S <pkg>
#   [AUR]   = Arch User Repo -> install with your AUR helper: yay/paru -S <pkg>
#   [core]  = base repo
#
# Bundled with lazy.nvim via git, so NOT Arch packages:
#   neovim plugins themselves (see lazy-lock.json)
#   treesitter parsers (built on demand)
#
# Most of the LSP/format/lint/dap tools are auto-installed by Mason on first
# launch (:Mason). Prefer the pacman/AUR package if you want them handled by
# the system package manager instead.

## Core (required)
- neovim          [extra]   # >= 0.11 (nightly recommended)
- git             [extra]
- gcc, make       [extra]   # `base-devel`; builds treesitter parsers + LuaSnip jsregexp
- tree-sitter-cli [extra]   # parser installs on the main branch
- ripgrep         [extra]   # grep/picker backend
- fd              [extra]   # file finder backend
- fzf             [extra]   # fuzzy matching
- curl, wget      [core]    # Mason downloads + nvim-dbee binary fetch

## Language runtimes (needed so the Mason tools actually run)
- nodejs, npm     [extra]
- pnpm            [extra]
- go              [extra]
- rustup          [extra]   # rust-analyzer / rustfmt / clippy as rustup components
- python          [extra]
- uv              [extra]   # python package manager
- lua51           [extra]   # Lua 5.1 for luarocks/nlua (Lua debugging)
- luarocks        [extra]
- zig             [extra]   # zig fmt (conform "zigfmt")

## Plugin build-time requirements (toolchains, not Arch packages)
- blink.cmp        -> cargo build --release          (rustup/cargo)
- LuaSnip          -> make install_jsregexp          (gcc + make)
- nvim-treesitter  -> C compiler + make + tree-sitter-cli
- nvim-dbee        -> curl/wget fetches prebuilt binary on install
